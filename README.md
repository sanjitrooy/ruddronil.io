# 🌐 Ruddranil.io - Web Developer & Digital Creative Platform
> **Complete GitHub & Vercel Deployment-Ready Website and Client Management System**

This website is custom-crafted to mirror the exact portfolio, digital services showcase, customer portal, and order tracking platform of **Ruddranil**. Built strictly with clean, modern **HTML5**, **CSS3**, and **Vanilla JavaScript** without heavy framework overhead.

---

## 📁 Exact File Architecture (ফাইলের তালিকা):

| File | Purpose |
|---|---|
| `index.html` | **Homepage**: Hero ("Hello, I'm Ruddranil"), About ("Turning Ideas Into Digital Experiences"), Services (01 to 05), Portfolio Feed, Work Tracking, and Contact Form |
| `login.html` | **Authentication**: Ruddranil.io account login, registration, and quick admin access |
| `customer-dashboard.html` | **Customer Dashboard**: Welcome banner, My Profile, My Orders, live order cards (RUD-...), and request submission |
| `admin.html` | **Admin Panel**: Master orders management, real-time status switcher (Pending, In Progress, Review, Delivered), progress %, and review moderation |
| `work-tracking.html` | **Live Project Tracker**: 4-step stepper (`#RUD-2026-001`), progress bar, and instant ID search |
| `portfolio.html` | **Portfolio & Work Feed**: Category filtering, project feed with like, comment, share, and modal details |
| `reviews.html` | **Reviews & Ratings**: 5-star rating system, verified reviews feed, and interactive submission form |
| `style.css` | **Full Dark Stylesheet**: Deep dark background (`#070b14`), royal blue accents, cards, forms, and responsive mobile layouts |
| `script.js` | **Public Site JS**: Order creation, tracking helpers, and shared state persistence |
| `admin.js` | **Admin Control JS**: Order status updates, deletion, progress adjustment, and JSON backup export |
| `reviews.js` | **Review System JS**: Star rating handler and dynamic review rendering |
| `vercel.json` | **Vercel Routing**: Clean URLs and static routing rules |
| `README.md` | **Deployment Guide**: Complete step-by-step GitHub and Vercel hosting instructions |

---

## 🚀 How to Run Locally (কম্পিউটারে চালু করার নিয়ম):
1. Double click `index.html` on your computer.
2. It will open immediately in any web browser with 100% functionality and zero dependencies!

---

## ⚡ 1-Click Deployment to Vercel (ভারসেলে হোস্ট করার নিয়ম):
1. Create a repository on [GitHub](https://github.com) (e.g. `ruddranil-portfolio`).
2. Upload these exact files to your repository.
3. Open [Vercel.com](https://vercel.com) and click **"Add New Project"**.
4. Import your GitHub repository and click **"Deploy"**.
5. Your website is live worldwide with SSL and lightning speed!
